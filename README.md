# Balcão

Loja online da Sites Express para qualquer negócio: pizzaria, hamburgueria, lanchonete, loja de roupas, loja de carros.

- Loja com sacola, opções (tamanho, adicionais, meio a meio) e pedido pelo WhatsApp
- Modo "interesse" para carros e imóveis, com simulador de financiamento
- Painel do lojista: pedidos, produtos, aparência (5 estilos de vitrine, paletas, letras) e configurações
- Sem banco de dados: a demonstração salva tudo no navegador

```bash
npm install
npm run dev
```
